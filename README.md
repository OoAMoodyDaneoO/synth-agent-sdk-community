# Synth Community

Welcome to the official community hub for **[Synth](https://pypi.org/project/synth-agent-sdk/)** — the Python SDK for building, deploying, and governing production-grade AI agents.

> Autonomous agents, engineered.

---

## What this repo is for

This is the place to:

- **Follow the roadmap** — see what's coming in v2.3.0 and beyond
- **Request features** — open an issue or start a discussion
- **Report bugs** — file a bug report against the SDK
- **Show and tell** — share agents you've built with Synth
- **Ask questions** — use Discussions for Q&A
- **Give feedback** — tell us what's missing, what's confusing, what's great

The SDK source code lives separately at [pypi.org/project/synth-agent-sdk](https://pypi.org/project/synth-agent-sdk/).

## Current version

## How to contribute to the community

**Filing a bug:** Use the [bug report template](../../issues/new?template=bug_report.md). Include your Synth version (`pip show synth-agent-sdk`), Python version, provider, and a minimal reproduction.

**Requesting a feature:** Use the [feature request template](../../issues/new?template=feature_request.md). Describe the problem you're trying to solve, not just the solution you have in mind.

**Sharing what you built:** Start a [Show and tell discussion](../../discussions/new?category=show-and-tell). We love seeing what people build.

**Roadmap feedback:** Comment on the pinned roadmap discussion or open a [Roadmap Feedback discussion](../../discussions/new?category=roadmap-feedback).

---

## Code of conduct

Be direct, be kind, be specific. We're all here to build better agents.

- Assume good intent
- Provide context when asking for help
- Keep feedback constructive
- No spam, no self-promotion without substance
